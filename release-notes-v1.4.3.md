# SitesSaver 1.4.3 — Upload progress fix

Small fix: while importing a backup, the progress modal showed the percentage twice
(*"Uploading (5%) 5%"*). It now reads *"Uploading 5%"*.

Nothing else changed.

## Install

Download `SitesSaver-1.4.3.zip` below, then **Plugins → Add New → Upload Plugin**. Existing
installs get the update through the normal Plugins screen.

Requires PHP 8.1+, WordPress 6.0+, and the ZipArchive PHP extension.
